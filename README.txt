SOFTWARE FJ - FASE 4

Requisitos: Python 3.9 o superior.

Ejecucion:
1. Abrir una terminal en esta carpeta.
2. Ejecutar: python main.py
3. Revisar eventos.log para ver los eventos y errores.

El programa utiliza listas en memoria y no usa base de datos.
Incluye 14 pruebas de clientes, servicios y reservas.
Las tarifas son valores de ejemplo y pueden modificarse.
